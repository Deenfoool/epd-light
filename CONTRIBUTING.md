# Contributing

1. Создавайте ветку от актуального `main`.
2. Используйте Node.js 22 и `npm ci`.
3. Вносите минимальные изменения без ослабления JWT, RLS, audit, billing и operator fail-closed границ.
4. Выполните `npm run check`.
5. Откройте pull request и дождитесь зелёного CI.

Не используйте реальные персональные данные, операторские токены, платёжные payload или ключевой материал в тестах.

Изменения схемы добавляются только новым migration-файлом. Уже применённые миграции не переписываются.
