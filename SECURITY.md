# Security policy

## Сообщение об уязвимости

Не публикуйте сведения об уязвимости, токены, персональные данные или рабочие документы в обычном issue.

Используйте приватный раздел **Security → Report a vulnerability** этого репозитория. В сообщении укажите:

- затронутый commit или версию;
- минимальные шаги воспроизведения;
- ожидаемое и фактическое поведение;
- возможное влияние;
- безопасный пример без реальных персональных данных и секретов.

## Границы продукта

`/api/operator/send`, реальная оплата и автоматическое удаление аккаунта намеренно отключены. Попытка включить их в обход проверяемых серверных границ считается security regression.

Секреты оператора, база данных, backup passphrase, service-role credentials и материалы КЭП никогда не должны попадать в `VITE_*`, браузерный код, Git, логи или issue.
